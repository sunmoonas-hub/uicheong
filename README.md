# 의좋은 폰프리 청 챌린지

의정부교육지원청 직원용 폰프리 챌린지 앱(2026. 11. 23.~12. 6.). 화면은 GitHub Pages, 서버는 Google Apps Script + 구글 시트입니다.
현재 단계: **회원가입·로그인·외부인 차단 + 매일 기록하기 + 게시판 + 팀 참여율**까지. 완수자 명단 추출은 다음 단계입니다.

## 기록 규칙

- 하루 1번, **어제** 하루를 기록합니다. 11. 23.의 기록은 11. 24.에, 마지막 날(12. 6.) 기록은 12. 7.에 입력합니다.
- 같은 날을 다시 저장하면 수정됩니다(시트에는 하루 1행). 지난 날짜를 나중에 몰아서 입력할 수는 없습니다.
- 항목: 어제 사용 시간(시간·분), 어제 지킨 실천(복수), 줄인 시간을 채운 활동 R·A·S·함께(복수, 또는 '없어요'), 한 줄 기록, 사진 1장(선택), 게시판 공유 여부.
- 사진은 휴대폰에서 긴 변 1280px로 줄여 Drive 비공개 폴더 `폰프리청챌린지_사진`에 저장하고, 게시판용 작은 썸네일은 `기록` 탭의 숨긴 열에 들어갑니다.
- 기간은 `설정` 탭의 `시작일`·`종료일`로 바꿀 수 있습니다.
- 데모에서는 주소 뒤에 `?today=2026-11-25`처럼 붙여 그 날짜로 시험합니다.

## 파일

- `index.html` 화면 전체 (첫 화면, 참여 신청, 로그인, 정지 안내, 홈)
- `config.js` 서버 주소, 팀 13개, 직위 목록, 기간, 개인정보 동의 문구 — **바꿀 것은 모두 여기서**
- `gas/Code.gs`, `gas/appsscript.json` Apps Script 서버
- `assets/` 교육지원청 로고, 의청이
- `docs/intent/` 의뢰 내용과 결정 사항

## 미리 보기 (데모 모드)

`config.js`의 `APPS_SCRIPT_URL`이 비어 있으면 데모 모드입니다. 입력이 그 브라우저에만 저장되고 참여 코드는 `1234`입니다.

```powershell
python -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다.

## 서버 설치 (처음 한 번)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다(예: `폰프리청챌린지_운영`).
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 내용을 `gas/Code.gs` 전체로 바꿉니다. 프로젝트 설정에서 'appsscript.json 표시'를 켜고 `gas/appsscript.json` 내용을 붙여 넣습니다.
4. 편집기 위쪽 함수 목록에서 `setup`을 고르고 **실행** → 권한 승인(시트·Drive). `참가자`, `기록`, `설정` 탭과 사진 폴더가 생깁니다. 나중에 `Code.gs`를 새 버전으로 바꿨을 때도 `setup`을 한 번 더 실행하면 빠진 탭·항목만 더합니다.
5. `설정` 탭의 **참여코드** 값을 `CHANGE-ME`에서 실제 코드로 바꿉니다. (그대로 두면 아무도 가입할 수 없습니다.)
6. **배포 → 새 배포 → 웹 앱**: 실행 사용자 **나**, 액세스 **모든 사용자**. 배포 후 나오는 `/exec` 주소를 복사합니다.
7. `config.js`의 `APPS_SCRIPT_URL`에 그 주소를 넣고 GitHub에 올립니다.

`Code.gs`를 고친 뒤에는 **배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다(주소는 그대로).

## 게시판·팀 참여율

- **게시판**: 기록할 때 '게시판에 나눌게요'를 켠 글만, 최근 순으로 12개씩 보입니다. 실명 대신 닉네임과 팀이 보입니다. 사진은 썸네일로 먼저 보이고, 누르면 Drive 원본을 앱을 거쳐 받아 크게 보여 줍니다(공개 링크를 만들지 않음).
- **부적절한 글 내리기**: `기록` 탭에서 그 행의 `공유` 칸을 **숨김**으로 바꾸면 게시판에서 빠집니다. 기록·참여율에는 그대로 남습니다.
- **팀 참여율** = 팀 기록 수 ÷ (팀 가입자 수 × 지금까지 기록할 수 있었던 날 수). 팀별 정원을 몰라 '가입한 사람이 얼마나 꾸준히 기록했나'로 잽니다. 정지된 계정은 빠지고, 결과는 2분마다 새로 계산합니다(새 기록 저장 시 즉시).
- 팀별 정원을 받을 수 있으면 '참여자 수 ÷ 정원'으로도 바꿀 수 있습니다.

## 운영자가 할 일

- **참여 코드**: `설정` 탭에서 바꿉니다. 메신저로 직원에게만 알리고, 포스터·QR에는 넣지 않습니다. 밖으로 샜으면 새 코드로 바꾸면 그때부터(최대 1분 뒤) 새 코드로만 가입됩니다. 이미 가입한 사람은 영향 없습니다.
- **모르는 사람 정지**: `참가자` 탭에서 성명·팀·직위·내선번호를 보고, 직원이 아니면 `상태`를 **정지**로 바꿉니다. 그 계정은 로그인해도 안내 화면만 보입니다. 다시 **정상**으로 바꾸면 풀립니다.
- **가입 막기**: `설정` 탭 `가입허용`을 `아니오`로.
- **비밀번호 잊은 직원**: 지금 단계에는 재설정 기능이 없습니다. 해당 행을 지우고 다시 가입하게 하면 됩니다(기록 기능이 붙기 전까지).
- `비밀번호해시`·`솔트` 열은 숨겨 두었습니다. 지우거나 고치지 마세요.

## 보안 메모

- 비밀번호는 솔트를 붙여 여러 번 해시한 값만 시트에 남습니다.
- 요청은 POST 본문으로 보내 비밀번호가 주소창·서버 로그에 남지 않습니다.
- 참여 코드는 서버에서만 검사하므로 화면 소스를 봐도 알 수 없습니다. 틀린 코드가 10분에 60번 넘게 들어오면 잠시 막고, 같은 닉네임 로그인 실패 8번이면 5분 막습니다.
- 로그인 토큰은 서버 비밀값(스크립트 속성 `TOKEN_SECRET`)으로 서명합니다. 앱을 열 때마다 서버에서 정지 여부를 다시 확인합니다.
