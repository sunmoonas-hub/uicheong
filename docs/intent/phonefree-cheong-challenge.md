# 의좋은 폰프리 청 챌린지 앱 — 의도 정리

작성일: 2026-11-21 · 의뢰: 권현순 부장님(감일) · 지시: 교육장님

## 목표 (Why)

교육장님이 의정부교육지원청 직원부터 폰프리를 실천해 보라고 하셔서, 감일고 라스타그램(학생용 라스온)과 비슷한 **직원 개인용 폰프리 챌린지 기록 앱**을 급히 만든다.
2주 동안 매일 폰 사용시간과 실천을 기록하고, 줄인 시간을 무엇으로 채웠는지 나누며, 팀별 참여율로 간식 팀을 정하고 완수자를 가려낸다.

- 정식 이름: **의청이와 함께하는 의좋은 폰프리 청 챌린지**
- 대상: 의정부교육지원청 직원 누구나 (약 100명 안팎), 개인별 참여, 가입 시 13개 팀 중 하나 선택
- 캐릭터: 의청이 (이미지 받음), 교육지원청 로고 사용

## 화면 구성 (부장님 앱 구성표 기준)

- **가입**: 성명, 팀명(13개 중 선택), **닉네임 + [중복 확인] 버튼**, **비밀번호 + 비밀번호 확인**, 나의 폰프리 다짐 1~2개, 개인정보 수집·이용 동의
  - 닉네임은 중복 확인을 통과해야 가입 가능(확인 후 닉네임을 고치면 다시 확인). 가입 저장 순간에도 서버가 한 번 더 중복 검사.
  - 게시판·순위 등 다른 사람에게 보이는 곳에는 실명 대신 닉네임(+팀)을 쓴다.
- **직원 확인(외부인 걸러내기)** — 2026-11-21 사용자 요청
  - 가입 시 기본 개인정보: 성명, 팀, 직위·직종(목록 선택: 장학사/주무관/교육공무직/기타 등), **사무실 내선번호**. 휴대폰 번호·생년월일·이메일은 받지 않는다(외부인 거르기에 필요 이상).
  - ~~직원명단 대조 자동 승인~~ — 직원명단을 받을 수 없어 폐기(2026-11-21).
  - **1차 관문: 참여 코드.** 가입 화면에 '참여 코드' 칸. 코드는 내부 공지(메신저·업무포털·청사 게시물)로만 알리고 앱·포스터·QR 주소에는 넣지 않는다. 코드는 시트 `설정` 탭에서 운영자가 바꿀 수 있고(유출되면 교체), 서버가 검사한다. 맞으면 바로 사용 가능.
  - **2차 관문: 운영자 사후 확인.** 시트 '참가자' 탭에 성명·팀·직위·내선이 쌓이므로 부장님이 훑어보고 모르는 사람은 상태를 '정지'로 바꾼다. 정지 계정은 로그인해도 안내만 보이고, 서버가 기록·게시판 요청을 거부하며, 게시판·순위·참여율에서 빠진다.
  - 이렇게 하면 직원은 기다리지 않고 바로 시작하고, 운영자가 100명을 하나씩 승인할 필요도 없다.
- **기록하기** (하루 1번, 어제 기준)
  - 어제 스마트폰 사용시간(분)
  - 어제 지킨 실천 체크(복수): 회의 중 폰 내려놓기 / 동료와 폰 없이 점심 산책·먼저 인사 / 잠들 땐 폰은 침대 밖 정해진 자리에 / 나의 다짐
  - **줄인 시간을 채운 활동**(‘채움 활동’이라는 말만 쓰지 않는다): R(독서) / A(예술·문화) / S(스포츠) / 함께(동료·가족 등과 한 일)
  - 한 줄 기록, 사진(선택)
